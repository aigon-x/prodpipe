# gtm

> Automatyzacja go-to-market — odkrywanie, budowanie, wdrażanie, skalowanie i uczenie się z rynku.

## 1. Purpose
Automatyzuje procesy go-to-market: odkrywanie rynku, budowanie oferty, projektowanie, przygotowanie, wdrożenie, skalowanie oraz uczenie się z wyników.

## 2. Owner
`STATUS: UNDEFINED`

## 3. Source of Truth
Strategie GTM, plany wdrożeniowe i metryki rynkowe przechowywane w repozytorium są źródłem prawdy dla procesów.

## 4. Contains
Skrypty powłoki: adopt.sh, build.sh, design.sh, discover.sh, launch.sh, learn.sh, prep.sh, scale.sh, validate.sh.

## 5. Does Not Contain
Nie zawiera samych materiałów marketingowych ani danych rynkowych — wyłącznie automatyzację procesów GTM.

## 6. Dependencies
Wymaga narzędzi do analizy rynku i zarządzania kampaniami oraz dostępu do danych rynkowych.

## 7. Consumers
Zespoły produktowe, marketingowe i sprzedażowe oraz procesy wprowadzania produktów na rynek.

## 8. Synchronization
Skrypty synchronizowane z repozytorium przez standardowy mechanizm dystrybucji narzędzi automatyzacji.

## 9. Lifecycle
Ewoluują wraz ze strategiami GTM; wersjonowane w git, aktualizowane przy zmianie procesów rynkowych.

## 10. Security
Skrypty nie przechowują sekretów; dane rynkowe podlegają polityce prywatności i kontroli dostępu.

## 11. Recovery
W razie awarii skrypty można uruchomić ponownie; plany i metryki są odtwarzane z repozytorium.

## 12. Drift Detection
Rozbieżności między skryptami a wersją w repozytorium są wykrywane przez mechanizm certyfikacji.
