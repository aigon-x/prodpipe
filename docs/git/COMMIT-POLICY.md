## Cel
Definicja zasad commitów.

## Zasady
Commit powinien:
- mieć jednoznaczny cel
- być atomowy
- być możliwy do rollbacku
- nie mieszać migracji z refaktorem
- nie mieszać infrastruktury z przypadkowymi zmianami
- mieć powiązanie z późniejszym work itemem
